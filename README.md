# Farm_diversity

Links farm-level management diversification metrics (land use, water management,
pasture management, and an overall "all practices" index) on Sustainable Cattle
Ranching (SCR) farms in Colombia to bird biodiversity estimates produced in the
sibling repo `../Ch1-ssp-birds/` (Chao et al. 2020 Hill-number diversity per farm,
via `Quarto_docs/02_Analysis_iNEXT.qmd`).

## Repository structure

- `Data/` — original, unmodified source data
  - `Complementary_Biodiversity_Paper_Birds_MJE_June_2026.xls` — farm management
    diversification indices and environmental covariates (94 farms), provided by
    Maria Esquivel. `Sheet1` holds the values; `Sheet2` is a column-label lookup.
  - `Bird_biodiversity_estimates/` — copies of `Tax_div_all_farms_06.04.26.csv` and
    `Tax_div_coverage65_06.04.26.csv`, generated in `../Ch1-ssp-birds/` (see that
    repo's `Quarto_docs/02_Analysis_iNEXT.qmd`). Farm-level Hill-number diversity
    estimates (species richness, Shannon, Simpson) per `[farm x data collector x
    year x season]` assemblage. `coverage65` is the stricter subset used for
    non-asymptotic (species richness, q=0) estimates; `all_farms` is the more
    complete set used for asymptotic (Shannon/Simpson, q=1/2) estimates.
  - `Working_Document_Final draft (advances) of science manuscript(s)_CORR_May_2026.docx`
    — background manuscript draft.
- `Derived/` — outputs generated by scripts (recreatable)
  - `Excels/Farm_diversity_matched.csv` — farm diversification indices, restricted
    to farms with an associated bird biodiversity estimate, joined to a farm-level
    biodiversity summary (mean richness/Shannon/Simpson, number of assemblages
    sampled).
  - `Excels/Farm_diversity_unmatched.csv` — the farms dropped for lacking a
    biodiversity estimate, kept for the matched-vs-unmatched comparison plot.
- `Figures/` — saved plots
- `Scripts/` — analysis scripts, run in numeric order

## Pipeline

1. `Scripts/01_Match_farm_diversity.R` — loads the farm diversification indices
   and the two bird biodiversity CSVs, keeps only farms present in
   `Tax_div_all_farms` (i.e. farms with an associated bird biodiversity estimate),
   and attaches a farm-level biodiversity summary. Exports to `Derived/Excels/`.
2. `Scripts/02_Farm_diversity_plots.R` — summary plots exploring the four
   diversification indices: distributions, correlations with each other and with
   farm covariates (canopy cover, elevation, biomass, distance to nearest SCR
   farm), pairwise relationships, and a matched-vs-unmatched comparison to check
   whether the farms dropped for lacking a biodiversity estimate look
   systematically different. Exports to `Figures/`.
