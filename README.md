# Farm_diversity

Links farm-level management diversification metrics (land use, water management,
pasture management, and an overall "all practices" index) on Sustainable Cattle
Ranching (SCR) farms in Colombia to bird biodiversity estimates (Chao et al. 2020
Hill-number diversity per farm). The diversity-estimation notebooks
(`Scripts/qmd/`) were moved here from the sibling repo `../Ch1-ssp-birds/` (full
git history preserved via `git filter-repo`), since this repo — not that chapter's
occupancy-modeling focus — is the natural home for the farm-diversity-estimation
work.

## Repository structure

- `Data/` — original, unmodified source data. **Not pushed to GitHub** (gitignored,
  local only):
  - `Complementary_Biodiversity_Paper_Birds_MJE_June_2026.xls` — farm management
    diversification indices and environmental covariates (94 farms), provided by
    Maria Esquivel. `Sheet1` holds the values; `Sheet2` is a column-label lookup.
  - `Bird_biodiversity_estimates/` — a static copy of `Tax_div_all_farms_06.04.26.csv`
    and `Tax_div_coverage65_06.04.26.csv` as last generated in `../Ch1-ssp-birds/`,
    before `02_Analysis_iNEXT.qmd` moved here. Farm-level Hill-number diversity
    estimates (species richness, Shannon, Simpson) per `[farm x data collector x
    year x season]` assemblage. `coverage65` is the stricter subset used for
    non-asymptotic (species richness, q=0) estimates; `all_farms` is the more
    complete set used for asymptotic (Shannon/Simpson, q=1/2) estimates. **These
    are a snapshot, not regenerated automatically** — see the Pipeline note below.
  - `Working_Document_Final draft (advances) of science manuscript(s)_CORR_May_2026.docx`
    — background manuscript draft.
- `Derived/` — outputs generated by scripts (recreatable)
  - `Excels/Farm_diversity_matched.csv` — farm diversification indices, restricted
    to farms with an associated bird biodiversity estimate, joined to a farm-level
    biodiversity summary (mean richness/Shannon/Simpson, number of assemblages
    sampled).
  - `Excels/Farm_diversity_unmatched.csv` — the farms dropped for lacking a
    biodiversity estimate, kept for the matched-vs-unmatched comparison plot.
  - `Excels/Bio_farms_unmatched.csv` — the reverse direction: farms with a bird
    biodiversity estimate but no matching row in the diversity-index spreadsheet.
    Currently just 3 (`Ref_El_hatico`, `Ref_La_luisa`, `Ref_Lucerna`) — reference/
    control sites outside the SCR farm-diversification survey, not a data problem.
- `Figures/` — saved plots
- `Scripts/` — analysis scripts
  - `qmd/` — the diversity-estimation notebooks moved from `Ch1-ssp-birds`
    (`02_Analysis_iNEXT.qmd`, `03_Farm_diversity.qmd`). Formatting simplified to
    plain HTML output (the original Elsevier-journal PDF template/`Suppfiles`
    dependency was dropped as unnecessary here). Read from `../Ssp-bird-data-wrangling/`
    and write to `Derived/Excels/`, same as in the original repo — a project-level
    `_quarto.yml` (`execute-dir: project`) keeps those relative paths resolving the
    same way.
  - `01_Match_farm_diversity.R`, `02_Farm_diversity_plots.R` — see Pipeline below.
- `_quarto.yml` — Quarto project config (`execute-dir: project`) for `Scripts/qmd/`.
- `Project_notes.md` — session notes. **Not pushed to GitHub** (gitignored, local
  only).

## Pipeline

1. `Scripts/qmd/02_Analysis_iNEXT.qmd` → `Scripts/qmd/03_Farm_diversity.qmd` —
   generate the farm-level bird biodiversity (Hill number) estimates from raw
   point-count data. Not yet re-run from this repo's new location (the export
   chunks are gated behind a `first_run` flag / an intentional `stop()`, meant to
   be run interactively, not via a full automated render) — `Data/Bird_biodiversity_estimates/`
   holds the last output from when these lived in `Ch1-ssp-birds`. Re-running
   `02_Analysis_iNEXT.qmd`'s export chunk would write fresh CSVs to
   `Derived/Excels/`, at which point `01_Match_farm_diversity.R` (below) should be
   pointed there instead of `Data/Bird_biodiversity_estimates/`.
2. `Scripts/01_Match_farm_diversity.R` — loads the farm diversification indices
   and the two bird biodiversity CSVs, keeps only farms present in
   `Tax_div_all_farms` (i.e. farms with an associated bird biodiversity estimate),
   and attaches a farm-level biodiversity summary. Exports to `Derived/Excels/`.
3. `Scripts/02_Farm_diversity_plots.R` — summary plots exploring the four
   diversification indices: distributions, correlations with each other and with
   farm covariates (canopy cover, elevation, biomass, distance to nearest SCR
   farm), pairwise relationships, and a matched-vs-unmatched comparison to check
   whether the farms dropped for lacking a biodiversity estimate look
   systematically different. Exports to `Figures/`.
